## What is PeerLLM?

PeerLLM is an experimental, networked AI platform built around distributed hosts and an orchestrator layer that coordinates traffic, workloads, and applications across the network.

The organization is exploring how agents, models, skills, and user-facing apps can work together as a peer-to-peer LLM ecosystem.

## Current focus

- Building the network foundations for PeerLLM hosts and orchestrators
- Experimenting with agent skill sharing and evaluation
- Shipping reference apps across web, desktop, mobile, and CLI surfaces
- Improving the public website and developer-facing documentation

## Why PeerLLM?

Because the future of AI should be:
- **Distributed** — work across many hosts and environments
- **Composable** — orchestrators, skills, hosts, and apps should plug together cleanly
- **Experimental** — fast iteration is part of the mission
- **Developer-friendly** — make it easy to build, test, and ship with the network
