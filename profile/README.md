# PeerLLM

> **Decentralized, People-Powered Artificial Intelligence**  
> Intelligence should belong to everyone — not just a handful of centralized data centers.

[PeerLLM](https://peerllm.com/) is a decentralized AI compute and inference network where everyday users, developers, and institutions run open-source large language models on their own hardware, serve real-time inference, and participate directly in the AI economy.

---

## What is PeerLLM?

PeerLLM replaces proprietary cloud monopolies with a distributed, privacy-first peer-to-peer alternative. Instead of routing queries through closed corporate data centers, PeerLLM coordinates a global network of independent host machines to execute AI workloads locally, natively, and collaboratively.

Whether run in **Local Mode** for private offline inference, **Hybrid Mode** for flexible workload offloading, or connected fully to the **Decentralized Network**, PeerLLM ensures complete ownership over compute, data, and models.

## The Tri-Nature Architecture

PeerLLM is structured across three core layers:

```
                  ┌─────────────────────────────────────────┐
                  │                CONSUMERS                │
                  │       P2P   •   P2S   •   S2S           │
                  └────────────────────┬────────────────────┘
                                       │
                                       ▼
                  ┌─────────────────────────────────────────┐
                  │                 NETWORK                 │
                  │    Routing  •  Accounting • Governance  │
                  └────────────────────┬────────────────────┘
                                       │
                                       ▼
                  ┌─────────────────────────────────────────┐
                  │                  HOSTS                  │
                  │      Compute  •  Data  •  Models        │
                  └─────────────────────────────────────────┘
```

* **Consumers:**
  * **P2P (Person-to-Person):** AI-mediated human collaboration, translation, and communication.
  * **P2S (Person-to-System):** Direct human-AI interactions for reasoning, creation, and problem solving.
  * **S2S (System-to-System):** Autonomous agents, APIs, and background services trading capabilities.

* **Network:**
  * **Routing:** Dynamically assigns tasks to optimal hosts based on capability, latency, and fairness.
  * **Accounting:** Tracks token flow and compute usage transparently.
  * **Governance:** Enforces ethical boundaries, service agreements, and network integrity.

* **Hosts:**
  * **Compute Providers:** Supply hardware processing power (GPUs/CPUs) for inference and fine-tuning.
  * **Data Providers:** Share specialized, high-quality domain datasets under clear host control.
  * **Model Providers:** Host pre-trained weights and fine-tuned open-source checkpoints.

## Core Ecosystem & Portals

* **[PeerLLM Network & Chat](https://peerllm.com/):** The public interface for private, community-hosted AI conversations, real-time node telemetry, host registration, and host desktop app downloads (macOS, Windows, Linux).
* **[PeerLLM SKILLs](https://skills.peerllm.com/):** A cross-model agent skill registry and evaluation engine. It lets developers author typed, testable agent skills, benchmark them against real models (LLooMA, Mistral, Qwen, Phi, and others), and publish verified capabilities.
* **[PeerLLM Models](https://models.peerllm.com/):** The live profile and registry of active LLMs distributed across the network, displaying real-time usage, node availability, and cross-model performance benchmarks.
* **[PeerLLM Blog](https://blog.peerllm.com/):** Deep technical writing, architectural guides, and updates detailing the evolution of LLooMA (the network-native orchestration layer) and JooMMA (the decentralized knowledge layer).
